# Eregion

Eregion is the virtualization laboratory for Middle-earth.

Its scope is:

- libvirt and QEMU
- cloud-init
- virtual machine images
- virtio-vsock host/guest communication
- repeatable local VM lifecycle experiments

Eregion will provide virtual machines for other labs to consume. Guest
configuration belongs in Imladris, and Kubernetes deployment belongs in
Khazad-dûm.

Status: project boundary established; experiments will be added incrementally.
